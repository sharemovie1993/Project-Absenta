### Heading Order
A heading level 3 (`<h3>`) is being used for the number "37" in the "Guru Aktif" section without following a logical sequence (e.g., starting with `<h1>`, then `<h2>`).
*   **Problem**: Screen reader users rely on headings to understand page hierarchy. Skipping levels or using them out of order makes navigation confusing.
*   **Fix**: Ensure your page starts with an `<h1>` for the main title and use `<h2>` for section titles. If the number "37" is just data, consider using a `<span>` styled to look large rather than a heading tag.

### Accessible Names
Several complex elements, such as the guru profile cards and the "GURU AKTIF" status card, have "mismatched" accessible names. This usually happens when an element has an `aria-label` that doesn't include the visible text inside it.
*   **Problem**: Speech-input users might try to click a button by saying the text they see, but if the internal "accessible name" is different, the command will fail.
*   **Fix**: Ensure any `aria-label` or `aria-labelledby` attributes include the visible text exactly as it appears on the screen.
