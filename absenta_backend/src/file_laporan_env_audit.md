LAPORAN AUDIT: ENVIRONMENT CONFIGURATION (BACKEND ABSENTA)

- 1. List ENV used in code
  - Aplikasi & Server
    - HOST, PORT, NODE_ENV — main.ts, bootstrap.ts — konfigurasi server.
    - BACKEND_NODE_ID, BACKEND_NODE_LABEL — bootstrap.ts — identitas node.
    - ENABLE_DEBUG_LOGS, CORS_DEBUG — infra/router.ts, bootstrap.ts — logging & CORS debug.
    - ALLOWED_ORIGINS, CORS_ALLOW_ALL, CORS_WILDCARD_BASES, ALLOW_LOCALHOST_WILDCARD — bootstrap.ts, auth.controller — kebijakan CORS.
  - Keamanan
    - JWT_SECRET — bootstrap.ts — signing token JWT.
  - URL Publik / Base URL
    - APP_URL, FRONTEND_URL, PUBLIC_APP_URL — berbagai controller/service — basis URL aplikasi.
    - PUBLIC_APP_SCHEME, PUBLIC_DOMAIN_BASE — auth.controller — skema & domain base tenant.
    - PUBLIC_INVOICE_BASE_URL — invoice.controller, subscription.controller — basis URL invoice publik (domain API).
  - Billing & Subscription
    - DUE_DAYS — subscription.controller, subscription.service — jatuh tempo invoice upgrade.
    - DEFAULT_TRIAL_END_BEHAVIOR — subscription.controller — perilaku akhir masa trial.
    - GRACE_PERIOD_DAYS — invoice public routes — masa tenggang.
  - Invoice
    - INVOICE_PDF_DOWNLOAD_WAIT_MS — invoice.controller, invoice public routes — delay unduh PDF.
    - INVOICE_PUBLIC_LINK_TTL_SECONDS — invoice.service, whatsapp.service — TTL token publik invoice.
  - Payment
    - MIDTRANS_SERVER_KEY, MIDTRANS_CLIENT_KEY, MIDTRANS_IS_PRODUCTION, MIDTRANS_WEBHOOK_URL — payment.config.
    - STRIPE_SECRET_KEY, STRIPE_PUBLISHABLE_KEY, STRIPE_WEBHOOK_SECRET, STRIPE_WEBHOOK_URL — payment.config.
    - XENDIT_SECRET_KEY, XENDIT_WEBHOOK_TOKEN, XENDIT_WEBHOOK_URL — payment.config.
    - TRIPAY_API_KEY, TRIPAY_PRIVATE_KEY, TRIPAY_MERCHANT_CODE, TRIPAY_WEBHOOK_TOKEN, TRIPAY_WEBHOOK_URL, TRIPAY_IS_PRODUCTION — payment.config; payment.service.
    - PAYMENT_CURRENCY, PAYMENT_EXPIRY_MINUTES, PAYMENT_CALLBACK_URL, PAYMENT_RETURN_URL — payment.config.
    - LOG_FILE_PATH — payment.service, whatsapp.service — path file log.
  - Redis & Cache
    - REDIS_URL, REDIS_PASSWORD — redis.config — koneksi Redis.
  - Email & Notifikasi
    - EMAIL_HOST, EMAIL_PORT, EMAIL_SECURE, EMAIL_USER, EMAIL_PASS, EMAIL_FROM — email.service — SMTP pengirim.
    - SMTP_HOST, SMTP_PORT, SMTP_SECURE, SMTP_USER, SMTP_PASS, SMTP_FROM_NAME, SMTP_FROM_EMAIL — email.service — alternatif SMTP.
    - NOTIFICATIONS_ENABLED — email.service, whatsapp.service — master switch kirim notifikasi.
    - WHATSAPP_API_URL, WHATSAPP_API_KEY, WHATSAPP_DEVICE_ID, WHATSAPP_WEBHOOK_SECRET — whatsapp.service, notification.controller — WhatsApp integration.
    - ALERT_EMAIL — berbagai service observability/notifikasi — alamat alert.
  - Observability & Retensi
    - MAINTENANCE_MODE — berbagai job — mode pemeliharaan.
    - USE_AGGREGATED_METRICS — observability.* — agregasi metrik.
    - LOG_RETENTION_ENABLED, LOG_RETENTION_BATCH_SIZE — jobs/logRetention.job.
    - METRIC_AGGREGATION_ENABLED — jobs/metricAggregation.job.
    - OBSERVABILITY_RETENTION_ENABLED, OBSERVABILITY_RETENTION_DAYS_QUEUE_JOB, OBSERVABILITY_RETENTION_BATCH_SIZE — observability.service.
  - Storage & Upload
    - INVOICE_PDF_STORAGE — invoice.service, pdf services — backend storage tipe.
    - S3_BUCKET, S3_REGION, S3_ENDPOINT, S3_ACCESS_KEY_ID, S3_SECRET_ACCESS_KEY, S3_FORCE_PATH_STYLE, S3_PRESIGN_EXPIRES_SECONDS — storage S3.
  - FCM / Push
    - FIREBASE_SERVICE_ACCOUNT_PATH, FCM_SERVER_KEY — notif push Parent App.
  - Face Recognition
    - FACE_EMBEDDING_URL — gerbang.service — layanan embedding wajah.
  - Lainnya
    - DEV_ALLOW_LOCALHOST_LOGIN, REQUIRE_EMAIL_VERIFICATION, ENABLE_PUBLIC_REGISTRATION, VERIFICATION_TOKEN_TTL_MINUTES — auth.controller — kebijakan auth/registrasi.

- 3. Audit URL Configuration
  - APP_URL — base aplikasi; di payment.config juga dipakai fallback.
  - FRONTEND_URL — base frontend; digunakan redirect halaman billing/checkout.
  - PUBLIC_APP_URL — base publik yang dapat dipakai bila FRONTEND_URL kosong.
  - PUBLIC_DOMAIN_BASE — membentuk domain tenant login/redirect.
  - PUBLIC_INVOICE_BASE_URL — memastikan link invoice publik menggunakan domain API.
  - Pemisahan domain:
    - api.absenta.id → backend API/public invoice.
    - {tenant}.absenta.id atau app.absenta.id → frontend tenant/PWA.
    - www.absenta.id → marketing site.

- 4. Audit Payment Flow Environment
  - Midtrans: MIDTRANS_* — webhook URL wajib memakai domain api.absenta.id.
  - Stripe: STRIPE_* — webhook URL domain API.
  - Xendit: XENDIT_* — webhook URL domain API.
  - Tripay: TRIPAY_* — webhook URL domain API; isProduction diatur oleh TRIPAY_IS_PRODUCTION.
  - Callback/Return URL: PAYMENT_CALLBACK_URL, PAYMENT_RETURN_URL — gunakan domain api.absenta.id.
  - Expiry: PAYMENT_EXPIRY_MINUTES — masa berlaku pembayaran.

- 5. Audit Redis Usage
  - REDIS_URL, REDIS_PASSWORD — koneksi.
  - Digunakan untuk: cache umum, queue/worker, locking (redis-lock.service), realtime pub/sub, invoice public token.
  - Catatan: Token publik invoice menggunakan Redis; pastikan TTL dan fallback email/WA tersedia untuk mitigasi kegagalan Redis.

- 6. Audit Email Configuration
  - EMAIL_* atau SMTP_* — pengirim email via nodemailer.
  - NOTIFICATIONS_ENABLED — master switch notifikasi.
  - EMAIL_FROM/SMTP_FROM_NAME/SMTP_FROM_EMAIL — hindari hardcoded sender.
  - Penggunaan: pengiriman invoice, verifikasi, reminder, dan alert.

- 7. Audit Storage Configuration
  - INVOICE_PDF_STORAGE: local atau s3.
  - S3_* — diaktifkan jika menggunakan S3; fallback local storage tersedia.

- 8. Audit Observability Variables
  - LOG_RETENTION_ENABLED/BATCH_SIZE — job retensi log.
  - METRIC_AGGREGATION_ENABLED — agregasi metrik.
  - OBSERVABILITY_RETENTION_* — retensi event/metrik observability.
  - Cron jobs dan cleanup tasks mematuhi flag di atas; aktif secara default.

- 9. Audit Security Variables
  - JWT_SECRET — digunakan untuk signing token (wajib tidak hardcoded di produksi).
  - WEBHOOK secrets/tokens per gateway — STRIPE_WEBHOOK_SECRET, XENDIT_WEBHOOK_TOKEN, TRIPAY_WEBHOOK_TOKEN.
  - Pastikan semua terset di environment produksi.

- 10. Audit Multi-Tenant Configuration
  - Tenant diidentifikasi melalui header X-Tenant-ID dan juga subdomain; middleware tenant.ts membaca header dan host.
  - PUBLIC_DOMAIN_BASE — membentuk URL subdomain tenant untuk login/redirect.
  - Rekomendasi ENV tambahan:
    - TENANT_BASE_DOMAIN (alias dari PUBLIC_DOMAIN_BASE) bila ingin penamaan lebih eksplisit.

- Rekomendasi Perbaikan .env.example
  - Tambahkan variabel yang hilang di daftar MISSING_IN_ENV_EXAMPLE.
  - Tegaskan penggunaan domain API untuk webhook & public invoice: PUBLIC_INVOICE_BASE_URL=https://api.absenta.id.
  - Konsistenkan dokumentasi ALLOWED_ORIGINS vs implementasi CORS.
