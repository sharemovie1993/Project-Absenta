# Industry-Standard SDLC Assistant Framework

Skill ini dirancang untuk memandu pengembangan aplikasi berstandar industri secara terstruktur melalui 6 Fase SDLC:

## 🧭 Navigasi 6 Fase Pengembangan

1. **Fase 1: Ideasi & Product Discovery (`phase-1-ideation`)**
   - Mengubah ide samar menjadi PRD (Product Requirement Document), Arsitektur Makro, MVP Scope, dan Technical Roadmap.
2. **Fase 2: Spesifikasi & Desain Fitur (`phase-2-feature-spec`)**
   - Merancang rancangan database (ERD), OpenAPI/REST contracts, UI state flow, dan breakdown tugas sebelum menulis kode.
3. **Fase 3: Pengembangan Clean Code & TDD (`phase-3-development`)**
   - Implementasi kode menggunakan Clean Architecture, SOLID Principles, TDD (Test-Driven Development), dan penanganan error tangguh.
4. **Fase 4: Hardening & Production Readiness (`phase-4-hardening`)**
   - Pengamanan aplikasi (OWASP Top 10), rate limiting, Caching, Query Optimization, Observability (Logging/Metrics), dan resilience.
5. **Fase 5: Audit Kode & Quality Assurance (`phase-5-audit`)**
   - Audit keamanan, linting, code review, pengujian batas (edge case), coverage test, dan analisis kebocoran memori/performa.
6. **Fase 6: Standarisasi & DevOps CI/CD (`phase-6-standardization`)**
   - Automasi CI/CD (GitHub Actions/GitLab CI), Containerization (Docker/Helm), Conventional Commits, dan Developer Guidelines.

## 📋 Cara Menggunakan
Saat pengguna memulai percakapan atau meminta panduan di salah satu fase, aktifkan fase yang relevan dan ikuti panduan terstruktur di dalamnya untuk menghasilkan output profesional berstandar enterprise.
